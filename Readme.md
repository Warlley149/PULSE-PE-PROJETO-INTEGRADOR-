# PULSE-PE

Projeto desenvolvido em Next.js para a plataforma PULSE-PE.

---

## 🛠️ O que você precisa ter instalado no computador

Antes de começar, certifique-se de ter os seguintes programas instalados na sua máquina:

1. **Node.js (LTS v20 ou superior)**
   - Verifique no terminal: `node -v`
   - Se não tiver instalado: [Baixar Node.js LTS](https://nodejs.org/)
2. **Git**
   - Verifique no terminal: `git -v`
   - Se não tiver instalado: [Baixar Git](https://git-scm.com/)
3. **VS Code** (ou editor compatível como Cursor / Windsurf)

### Extensões Recomendadas para o VS Code

Ao abrir este projeto no VS Code, você receberá uma notificação recomendando as extensões configuradas. Se preferir instalar manualmente, busque por:

- **GitHub Pull Requests and Issues** (`github.vscode-pull-request-github`)
- **GitLens** (`eamodio.gitlens`)
- **ESLint** (`dbaeumer.vscode-eslint`)
- **Prettier - Code Formatter** (`esbenp.prettier-vscode`)
- **Error Lens** (`usernamehw.errorlens`)
